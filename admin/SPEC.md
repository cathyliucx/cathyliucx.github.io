# 项目发布器规格

## 目标

为 Cathy Liu 的 GitHub Pages 个人站点提供一个浏览器内内容发布界面。内容可以是研究报告、方法学习与综述，也可以是生活记录与随感。用户填写内容并确认后，应用一次性创建文章页、更新对应栏目并提交到 GitHub。

## 技术与结构

- 纯 HTML、CSS 与浏览器 JavaScript，不引入依赖。
- GitHub Fine-grained Token 仅保存在当前浏览器标签页。
- 使用 GitHub Git Data API 创建原子提交。
- 支持 AI、量化与生活三个栏目。

## 内容结构

- 列表：标题、摘要、关键词与文章链接。
- 文章页：自由正文，不强制固定章节。

## 安全边界

- 不把 Token 写入源码、提交或永久存储。
- 不使用强制推送。
- 发布前显示预览并要求用户确认。
- Token 只需要目标仓库的 Contents 读写权限。

## 验收标准

- 可以验证 GitHub 连接。
- 可以实时预览项目内容。
- 可以生成安全的文章路径和 HTML。
- 可以在一个 Git 提交中创建文章页并更新对应栏目。
- 发布成功后显示项目地址与部署提示。
